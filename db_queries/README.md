# Database scripts

- **`legacy-mssql/`**: the original SQL Server scripts from the group project, kept for history.
- **Current schema**: [`server/src/main/resources/db/migration`](../server/src/main/resources/db/migration). This is the MySQL 8 / MariaDB translation. The Ktor server applies it automatically on startup and records it in `schema_migration`.

Demo data is generated by `server/src/main/kotlin/com/unyieldingmight/server/db/DevSeeder.kt`, so class dates are always upcoming. It is skipped when `SEED_DEMO_DATA=false`.
